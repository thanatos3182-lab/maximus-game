PUT YOUR OWN BACKGROUNDS HERE (optional)

The game uses these 3 files automatically when they exist. Missing file = the built-in placeholder cave is used.

  cave_far.png    slowest layer (distant stuff, can be fully painted, no transparency needed)
  cave_mid.png    middle layer  (use a transparent background)
  cave_near.png   closest layer (use a transparent background: vines, stalactites, foreground rocks)

Size: make each one about 2048 x 776 pixels. The left and right edges must line up
(seamless), because the picture repeats as you scroll.
Scroll speeds: far 0.15, mid 0.35, near 0.6.
